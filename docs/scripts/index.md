# Scripts

Reference for helper scripts in `scripts/`.

## Alias installer

Run `scripts/install_aliases.sh` to install common PyPNM-CMTS aliases into your shell rc file.

## Common aliases

- `pypnm-cmts-release` - run the release helper.
- `pypnm-cmts-release-hot-fix` - run the hot-fix release helper (build bump on `hot-fix`).
- `pypnm-cmts-version-check` - verify version consistency.
